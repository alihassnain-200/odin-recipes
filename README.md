# odin-recipes
odin-recipe-website-project

In this project I make a simple, blank homepage that lists recpies.

Each list of recipe is a link that connects you with the relevant recipes on the other html pages.

Each recipe page has a recipe title, image of that recipe, a short description, ingridients, and lastly
the steps you need to follow to make that recipe.

At the start of each recipe page is a link that takes back to the home page.

There are total of 5 recipes and the format described above is followed for all of them. Exceptionally,
some recipes may have include fillings before the ingridients.
